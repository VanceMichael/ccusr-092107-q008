# 公积金异地提取裁定

保存公积金政策、申请材料、余额占用和支付裁定。

## 领域规则

- **按受理时点与住房所在地取版**：政策以城市为单位分版本配置生效区间，裁定时按 *受理时间* 和 *住房所在地* 选版并固化为快照；三天后作出决定时政策即使修订（如装修额度由 10 万调为 8 万），仍按原版本计算，不溯及既往。
- **九种提取场景**：购房、建造翻建大修、租房、还贷、装修、物业费、适老化改造、加装电梯、大病医疗。
- **缴存互信互认**：互认生效日后，外地缴存月数与本地合并核验缴存连续性；生效日前只计本地。
- **核验项**：账户可用余额、家庭授权（适老化改造、加装电梯等）、消费凭证（有效性与场景一致）、年度额度与历史占用、提取频次限制。
- **三日办理期限**：受理日起三日；依法补件中止的时段从期限中**顺延扣除**，中止未结束不得作出决定。
- **重复提交**：线上与窗口同人、同场景、同住房、同周期的提交合并为同一案件，不改变受理时点。
- **撤回重提**：撤回后重提沿用原受理时点与原政策版本；撤回件不得作为新申请重复受理。
- **跨城转移冻结**：转移期间余额全部冻结，不可提取；转移解冻后方可裁定支付。
- **银行并发支付**：以案件号为幂等键，并发请求只产生一笔真实扣款。
- **骗提追缴**：获批支付后认定骗提的，按真实支付结果追回，历史提取标记追缴，并登记三年使用限制；骗贷为五年限制。
- **复议**：只能引用原裁定版本快照和真实支付结果，不得按当前政策重算。

## 目录

- `fixtures/policies.json`：两个虚构城市的政策版本、生效区间、九场景规则（额度、缴存月数、凭证、家庭授权、频次）与互认生效日。
- `fixtures/accounts.json`：虚构账户样例，含余额、跨城转移冻结、外地缴存、家庭授权、凭证、历史占用及限制。
- `src/policies.py`：时点取版与规则查询。
- `src/accounts.py`：账户台账（余额/冻结/占用/缴存/授权/凭证/历史/限制）。
- `src/cases.py`：受理去重、撤回重提、补件中止。
- `src/adjudication.py`：核验、额度试算与裁定快照。
- `src/payments.py`：银行幂等支付与真实支付结果。
- `src/enforcement.py`：骗提追缴与限制登记。
- `src/review.py`：复议（原版本 + 真实支付）。
- `src/timeutil.py`：三日期限与补件扣除。
- `tests/test_adjudication.py`：端到端规则测试。

示例中的编号、金额、主体均为虚构值，不包含账号、凭据或真实个人信息。
