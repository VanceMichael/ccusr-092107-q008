# 公积金异地提取裁定

保存公积金政策、申请材料、余额占用和支付裁定。

## 领域资料

`contracts/` 约定资料格式，`fixtures/` 提供不含真实个人信息的示例。代码模块只负责读取和校验这些资料，后续业务服务可以沿用其中的领域标识与版本约定。

- `contracts/context.schema.json` / `fixtures/context.json`：领域标识与业务事实
- `contracts/policies.schema.json` / `fixtures/policies.json`：城市政策版本（示例市两个版本、邻市一个版本）
- `contracts/accounts.schema.json` / `fixtures/accounts.json`：账户样例（含转移冻结、历史提取、限制记录）

当前资料记录了以下业务事实：

- 提取场景由六种扩展为九种
- 缴存记录将实现全国互信互认
- 违法提取和骗贷对应不同期限的使用限制（样例中为 3 年与 5 年）

## 裁定模型

- `src/policy.py`：政策版本库只增不改，同一城市版本号不得改写、生效区间不得重叠；按（住房所在地，受理日期）解析版本
- `src/domain.py`：申请、账户、补件中止区间、裁定与支付记录
- `src/deadline.py`：三日办理期限，补件依法中止的时间从中扣除
- `src/adjudication.py`：裁定引擎。核验账户余额（扣除转移冻结）、家庭授权、消费凭证和历史占用；线上与窗口重复提交归并同一在办件；撤回重提按新的受理时间裁定；骗提追缴记入限制记录
- `src/payments.py`：支付台账，同一裁定只支付一次，银行并发请求返回首次结果
- `src/reconsideration.py`：复议只引用原裁定记录的政策版本和台账中的真实支付结果

核心约束：裁定按**受理时间**与**住房所在地**适用的政策版本作出，受理之后、裁定之前的政策修订不影响在办件；复议同样锁定原裁定版本。

## 本地校验

```sh
python -m unittest discover -s tests -t .
```

运行项目自带测试可确认示例资料能够读取，且领域标识、版本和事实列表完整。示例中的编号均为虚构值，不包含账号、凭据或真实主体信息。
